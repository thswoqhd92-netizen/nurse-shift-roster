# 간호사 근무표 자동화

병동 근무표를 만들고, 개인·전체 달력으로 보고, 파일로 공유하는 웹 앱입니다.
서버 없이 HTML로 동작하며, 데이터는 브라우저에 저장됩니다.

## 실행 방법

### Windows (집·사무실 PC)

1. 이 폴더에서 **`실행.bat`** 더블클릭 → 브라우저가 열리고 근무표가 실행됩니다.
2. 이미 실행 중이면 **`열기.bat`** 으로 화면만 다시 엽니다.
3. Cursor / VS Code에서는 `Ctrl+Shift+B` 로 **실행**, 명령 팔레트에서 작업 **열기** 를 고를 수 있습니다.

Python이 없어도 `index.html` 로 바로 열립니다.

### 웹에서 바로 열기

GitHub Pages가 켜져 있으면 저장소 페이지의 **Pages** 주소로 열 수 있습니다.
(각 PC·휴대폰 브라우저마다 근무표 데이터가 따로 저장됩니다.)

## 공유

앱의 **공유** 탭에서

- **전체 보기 파일** / 개인 **파일** → 카카오톡으로 보내면 컴퓨터가 꺼져도 휴대폰에서 볼 수 있습니다.
- **링크** → 같은 Wi‑Fi에서 이 PC가 켜져 있을 때만 됩니다.

## 파일

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 시작 화면 |
| `app.js` | 화면·저장·공유 |
| `scheduler.js` | 근무표 규칙·자동 배정 |
| `styles.css` | 모바일 포함 스타일 |
| `실행.bat` / `열기.bat` | Windows에서 실행·열기 |
| `휴대폰용.html` | 예시 데이터가 들어간 단일 파일 (참고용) |

## 사무실 PC에 설치

1. GitHub에서 이 저장소를 **Code → Download ZIP** 하거나 `git clone` 합니다.
2. 압축을 풀고 **`실행.bat`** 을 누릅니다.
3. 또는 Pages 주소로 브라우저만 엽니다.
